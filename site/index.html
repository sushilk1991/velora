The mechanic

One key. No new app to learn.

Velora never asks you to say “new line” or “comma.” You hold a key, you talk, you let go. Everything between those two moments happens on your machine.

  1. 01

    Hold

    Right Option by default, or any shortcut you prefer. A small pill appears near your cursor — it never steals focus from the field you are typing into.

    ⌥
  2. 02

    Talk

    Ramble. Pause. Change your mind halfway through a sentence. Velora is built around the way people actually speak, not the way dictation software wishes they did.

  3. 03

    Release

    Cleanup runs locally, the text is pasted at your cursor, and it also stays on the clipboard — so nothing is lost if the app you are in refuses an automatic paste.

    lands right here

Destination-aware

The app you’re in decides the format.

Velora reads which app is in front and switches its formatting rules. Slack gets a message. Mail gets paragraphs. Your editor gets your identifiers back verbatim, with no trailing period to break the command.

Message

Slack · Messages · WhatsApp

“are we still on for thursday i can move things around if not”

Are we still on for Thursday? I can move things around if not

Terse. No invented greeting. A short line keeps its missing full stop.

Email

Mail · Outlook · Spark

“thanks for sending that over i read it last night separately we should talk about the pricing page before friday”

Thanks for sending that over — I read it last night.

Separately, we should talk about the pricing page before Friday.

Paragraph breaks where the topic shifts. Never invents a sign-off you didn’t say.

Note

Notes · Obsidian · Bear

“first pull the logs second check the retry counter third file the ticket”

1. Pull the logs
2. Check the retry counter
3. File the ticket

Spoken ordinals become a numbered list. Plain prose stays prose.

Code

VS Code · Zed · Terminal

“git commit dash m fix the retry backoff”

git commit -m "fix the retry backoff"

Verbatim. Nothing capitalised, no trailing period — a period breaks a shell command.

Private by architecture

Not a policy. A missing network call.

Alpha Velora for iPhone

An early experiment, not a product yet.

The iPhone companion turns the Action Button into a voice key: press, speak, finish, and the transcript is on your clipboard. Recognition is on-device, using Apple’s own speech models.

It is alpha and it is not stable. Expect rough edges, bugs, and breaking changes between commits. It is not on the App Store, there is no TestFlight build, and it is not something to depend on. Build it only if you are comfortable running unfinished software from source.

Install

Free to install. Yours for good.

Download the signed, notarised app or install it with Homebrew. On first launch Velora asks for microphone, input-monitoring, and accessibility permissions, then downloads the models it needs. Setup takes a few minutes and needs the internet once — after that, dictation is local.

Straight answers

Before you install.

Does Velora ever touch the network?

Models download once during setup, and optional update checks contact GitHub. During dictation, speech recognition and cleanup run locally — your audio and transcript are not uploaded. Update checks can be turned off.

What Mac do I need?

An Apple Silicon Mac running macOS 14 or later. Disk use depends on which speech and cleanup models you pick; Velora chooses a cleanup tier based on how much RAM you have.

Is it really free?

Yes. It is MIT-licensed and open source, with no account, no subscription, and no paid tier. There is nothing to upsell you because there is no server to pay for.

Is the iPhone app in the App Store?

No — and it is worth being blunt: the iPhone app is alpha and unstable. The Xcode project is in the repository and builds on iOS 17 or later, but it is unfinished, changes without warning, and is not something to rely on. The Mac app is the real product.

How do I get help?

Email sushilk.1991@gmail.com or open a GitHub issue. Velora is pre-1.0 and actively developed; bug reports genuinely help.
