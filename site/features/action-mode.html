Velora/Features/Action Mode

Feature · new

Say the errand.
Watch it run.

Hold ⌃⇧A and speak — “message Priya on Slack that I’m running late,” “search YouTube for the match highlights.” Velora opens the app and does it, planning on your Mac with the same local models that clean your dictation.

Download for Mac ↓ Install options

How it works

An agent, not a macro.

Recorded macros break the moment a window moves. Action Mode works the way you would: act a few steps, look at the screen, adjust.

Plan locally

Your words become steps

The on-device language model turns your sentence into a structured plan of small, closed primitives — open this app, press this control, type this text. No cloud round-trip, ever.

Read the screen

Reality checks between steps

Velora reads what the screen actually says as it goes — pressing the right person’s chat when a shortcut didn’t land, correcting a misheard name to the spelling it can see in front of it.

Stop, don’t guess

Wrong window, no action

If the window in front is not the one it expects, Velora stops rather than act on the wrong thing. A half-done errand you can see beats a confident mistake you can’t.

“Draft”

Written, but unsent

Say “draft” and Action Mode stops with the message composed but not sent — the send stays yours. It also keeps a private, local record of what it did, cleaned up automatically.

The fine print

  • Action Mode uses a closed set of primitives — it cannot run arbitrary shell commands, and Velora refuses to add that on purpose.
  • It acts through the same accessibility permission as dictation; there is no network port and no remote control surface.
  • It is new and deliberately conservative: expect it to stop and tell you rather than push through ambiguity.
  • Every action happens on your Mac, visibly — you can watch it work and take the keyboard back at any time.
