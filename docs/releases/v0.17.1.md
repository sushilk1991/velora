# Velora 0.17.1

Chrome joins the context-aware party. Gmail, Notion, Docs, and every other
web app now get the right writing style in Chrome, Brave, Edge, Arc, and
friends — Velora reads the page address straight from the browser.

- The first time, macOS asks once: "Velora would like to control Google
  Chrome." Allowing it lets Velora read the current tab's address and title —
  that's all it's used for, and nothing leaves your Mac.
- Chrome window titles with a profile name ("… — Google Chrome — Sushil") are
  understood correctly.
- Safari and Firefox-family browsers keep working without any new permission.
- Action Mode sees Chrome pages too, so multi-step web tasks stay on track.
- Good to know: when Chrome auto-updates in the background, macOS stops
  letting any app talk to it until Chrome restarts. Velora now detects that
  state and quietly resumes once Chrome relaunches.
