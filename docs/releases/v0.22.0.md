# Velora 0.22.0

A new icon, and a settings window and HUD that finally speak with one
voice.

- New app icon: a serif V with a coral full stop, matching the website.
- Every pane uses the same corner radii, motion, warning and success
  colours, and one symbol per feature.
- Buttons and menu items read the same everywhere: Stream Typing, Voice
  Edit, Proofread, Action Mode, Start Meeting Notes, Finish Notes.
- Dictionary rows say Remove for words you added and Forget for words
  Velora learned. History’s Clear All is now Delete All and asks first.
- The Shortcuts pane no longer claims Action Mode opens other apps on its
  own; that needs the optional Cua Driver.
- The meeting-end prompt offers Keep Recording in full.

## Upgrade

Replace the existing app in Applications with the new DMG, or update
in-app. Preferences, history, modes, and dictionary entries are
preserved.
