# Velora 0.29.6

Action Mode no longer quits when a command needs a keyboard shortcut.

- Commands such as "create a new note in Notes" press shortcuts like ⌘N.
  Velora could quit before pressing them. It now presses them as planned.
- Fix spelling and grammar replaces the selected text in web pages, Gmail,
  Slack, and other Chromium and Electron apps instead of leaving the result
  on the clipboard. The pill shows what changed: removed words struck through
  in red, added words in green.
- When a dictation ends with no words, Velora says why: "Mic is silent" when
  the microphone sent no sound, "Didn't hear any speech" when it heard only
  quiet, and "Couldn't transcribe. Try again" otherwise.
- Speech recognition and writing cleanup still run on this Mac. Preferences,
  history, modes, and dictionary entries are preserved.
