# Velora 0.18.25

Action Mode now keeps compatible work in the background and leaves the app
you are using alone.

- Velora no longer brings another app forward while an Action is running.
  A result card reports what happened; clicking it opens the exact app window.
- Result cards distinguish a verified completion, an app that is ready, and
  work that ran without enough proof. Velora never labels an unverified send
  as completed.
- If an app cannot expose a safe background target, the Action stops instead
  of typing into a guessed field or stealing focus.
- Using Telegram or another app during an Action no longer blocks unrelated
  background work. If you enter the target app itself, Velora waits rather
  than competing for its controls.
- Pending dictation history now finishes saving when Velora quits, including
  an idle quit immediately after transcription.
