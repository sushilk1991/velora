# Velora 0.26.0

Modes, Meetings and Dictionary now work from the keyboard, the window
keeps the size you give it, and a short dictation after a pause is
ready sooner.

## Modes

- Modes is a list, like Meetings. Click a mode to edit it in place:
  name and formatting, instructions, apps, vocabulary and
  replacements, with Back, Duplicate, Delete or Reset, and Save.
- Switching pages or quitting with unsaved edits asks first: Save,
  Don't Save or Cancel. An update waits until you've saved.
- If another app changes a mode's file while you edit it, Velora
  won't overwrite it.

## Meetings

- The arrow keys move through meetings and search results, Return or
  Space opens one, and ⌘[ goes back to the meeting you left.
- A link in a meeting's notes shows or hides its transcript, in the
  Meetings page and in the notes window. It no longer sticks at "No
  transcript is available." while the first transcription runs.
- A failed read of the meetings database at launch no longer deletes
  meeting recordings, and a meeting's audio is removed only after the
  meeting itself is gone.
- "Mac audio" replaces "computer audio" everywhere.

## Dictionary

- The list works from the keyboard. The arrows, Home, End, Page Up
  and Page Down move the selection, Return edits, and Delete asks
  before removing a word. After a change, the selection stays near
  where it was.
- VoiceOver reads each word as one row, with Remove, Edit and Make
  Permanent actions.
- Make Word Permanent opens the editor first, so you can fix the
  spelling before you keep it.

## Window and Home

- Switching pages no longer makes the window grow, and the main and
  Settings windows reopen where you left them.
- Start Dictation on Home copies your text to the clipboard instead
  of typing into the app in front.
- The sidebar says what the speech engine is doing: starting, loading
  models, updating after an app update, or what went wrong.
- ⌘1 to ⌘6 open each page. In onboarding, one press of Return moves
  one step, and the shortcut recorder cancels on Esc.

## Speed and reliability

- Velora readies the cleanup model while it is still transcribing. A
  short dictation after a minute or more of quiet is typically ready
  in 0.9 seconds instead of 1.6.
- If the cleanup model stops responding, Velora starts a new one in
  the background instead of leaving dictations uncleaned until you
  relaunch.
- Parakeet v3 makes fewer mistakes. It transcribes each stretch of
  speech between pauses as a whole, instead of in half-second steps.
- Everything still runs on this Mac.

## Upgrade

Replace the existing app in Applications with the new DMG, or update
in-app. Preferences, history, modes, and dictionary entries are
preserved.
