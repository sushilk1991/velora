# Velora 0.28.0

Action Mode now plays the YouTube video you ask for, and it opens the
copy of an app you used last.

## Action Mode

- Say "play lofi on YouTube", "open YouTube and then play Coke Studio",
  or "YouTube, play Despacito". Velora searches YouTube in your browser
  and starts the first result. It reports done only once the video's
  page has loaded. In testing this took about 2.5 seconds.
- A command that does more than play, such as "play this and send it
  to Priya", still goes step by step.
- Cancelling a play command stops it before the video starts.
- When more than one copy of an app is running, such as Chrome with
  two profiles, Velora uses the one you used last. Before, "open
  Google Chrome" could fail with "not found".
- A browser that an automation tool started, such as an AI agent's
  Chrome, is never used. If only those are running, Velora starts your
  own.
- Web pages open in the browser you used last, and it comes to the
  front, also when actions run in the background.
- Background actions work with Cua Driver 0.30.
- Everything still runs on this Mac.

## Upgrade

Replace the existing app in Applications with the new DMG, or update
in-app. Preferences, history, modes, and dictionary entries are
preserved.
