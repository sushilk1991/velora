# Velora 0.29.1

Velora releases unused memory after dictation and does less work while idle.

- The default speech model releases unused buffers after dictation and
  stays loaded for the next one.
- Download progress updates only when it changes.
- Connection retries stop while the engine is connected and resume when
  it disconnects.
- Dictation skips live drafts when Stream Typing is off.
- Engine diagnostic logs are limited to two 5 MB files.

Speech recognition and writing cleanup still run on this Mac. Preferences,
history, modes, and dictionary entries are preserved.
