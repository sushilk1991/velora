# Velora 0.35.1

- Press `Space` during any ordinary dictation to stop, paste, and send immediately without releasing your Push-to-Talk key or hitting Return afterward. Customize or disable the in-recording Send key in Settings › Shortcuts alongside the dedicated `⌃⇧↩` Dictate & Send shortcut.
- Shows a `Send [Space]` hint in the Live Transcript Card footer during regular dictations whenever in-recording send is active for the current app.
- Fixes an issue where lifting a held Push-to-Talk modifier right after triggering Send could cancel the automatic Return keystroke.
