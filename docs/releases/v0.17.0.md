# Velora 0.17.0

Dictation now understands where you are writing. Compose in Gmail and it
formats like an email, write in Notion and it formats like a note, chat in
Slack and it stays casual — in native apps and in the browser.

- In Safari, Zen, and Firefox-family browsers, Velora reads the page address
  itself, so Gmail, Notion, Linear, Google Docs, Telegram Web, Teams, and
  many more get the right style even when the tab title doesn't name the
  app. (Chrome blocks assistive context for all apps; Chrome tabs keep the
  general style for now.)
- Many more apps get the right mode out of the box: Signal, Teams, Telegram,
  Mimestream, TextEdit, Word, Pages, Drafts, Things, Sublime Text, Xcode,
  JetBrains IDEs, WezTerm, Firefox, Brave, Edge, Vivaldi, Opera, Orion, Zen,
  and more.
- The recording pill shows the detected style — "Email" in Gmail, "Notes" in
  Notion — instead of a generic "Browser".
- Email dictation places greetings and sign-offs on their own lines and keeps
  paragraphs cleanly separated. Improvements to built-in styles reach existing
  installs, but any style you've edited is always left untouched.
- Action Mode can now open links on web pages — "open the first result" works
  in supported browsers — and it sees the page address, so multi-step web
  tasks stay on track. Voice-driven web addresses are locked down harder:
  a link can only carry words you actually spoke.
