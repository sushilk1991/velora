# Velora 0.17.0

Dictation now understands where you are writing. In a browser, Velora reads
which web app you're on — compose in Gmail and it formats like an email, write
in Notion and it formats like a note, chat in Slack or WhatsApp Web and it
stays casual.

- Web apps are recognized by the page itself, not just the tab title, so
  Notion, Linear, Google Docs, Telegram Web, Teams, and many more get the
  right style automatically.
- Many more apps get the right mode out of the box: Signal, Teams, Telegram,
  Mimestream, TextEdit, Word, Pages, Drafts, Things, Sublime Text, Xcode,
  JetBrains IDEs, WezTerm, Firefox, Brave, Edge, Vivaldi, Opera, Orion, and
  more.
- The recording pill shows the detected style — "Email" in Gmail, "Notes" in
  Notion — instead of a generic "Browser".
- Email dictation places greetings and sign-offs on their own lines and keeps
  paragraphs cleanly separated. Improvements to built-in styles reach existing
  installs, but any style you've edited is always left untouched.
- Action Mode can now open links on web pages — "open the first result" works —
  and it sees the page address, so multi-step web tasks stay on track.
