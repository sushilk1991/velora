# Velora 0.29.3

Velora sets up its speech engine on Macs where Homebrew's Python is 3.15.

- New installs no longer stop at "Connecting to the model engine…" in
  Settings › Models. Setup now uses Python 3.12 to 3.14 and skips 3.15,
  which the speech and writing models do not support yet.
- An engine that failed to start on Python 3.15 is rebuilt on a supported
  version the next time Velora opens.
- Speech recognition and writing cleanup still run on this Mac. Preferences,
  history, modes, and dictionary entries are preserved.
