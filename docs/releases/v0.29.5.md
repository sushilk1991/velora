# Velora 0.29.5

Dictation works with USB microphones that send their sound on the second
channel.

- Some USB webcams and stereo microphones carry sound on one channel only.
  Velora listened to the first channel alone, so with these microphones
  every take ended in "Couldn't transcribe. Try again." Velora now mixes
  every channel the microphone sends.
- Speech recognition and writing cleanup still run on this Mac. Preferences,
  history, modes, and dictionary entries are preserved.
