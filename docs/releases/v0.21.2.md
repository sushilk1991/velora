# Velora 0.21.2

Install Update now quits and reopens Velora when your work is finished.

- Fixes updates stuck on “Waiting to Install…” while Velora is idle.
- Waits for queued audio-file transcriptions before restarting.
- Keeps an update you requested if you quit during its final check,
  while respecting your choice to leave the app closed.
- Recovers from verification tools that stop responding.

## Upgrade

If the old updater is stuck, install this release from the DMG or Homebrew.
Preferences, history, modes, and dictionary entries are preserved.
