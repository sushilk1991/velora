# Velora 0.18.1

Stream Typing works again in Slack, VS Code, Discord, Chrome, and every
other app built on the same engine. It had been typing the first few words
and then stopping — leaving them highlighted, where the next key you pressed
wiped them out. The whole dictation now lands, live, as you speak.

- If Stream Typing has been unreliable for you, it was probably this. Native
  apps like Notes, TextEdit, and Mail were never affected, which is why it
  looked intermittent rather than broken.
- Nothing about what Velora will type over has changed. It still refuses to
  replace anything it cannot prove it wrote, and still leaves your text alone
  the moment you move the cursor yourself.
- Voice actions no longer stall waiting for an app that is open but behind
  another window. Velora brings it forward and carries on, instead of
  spending the whole attempt waiting for something to happen on its own.
- When an action can't finish, it now tells you what actually went wrong —
  "TextEdit has no text field to type into" rather than an internal message
  about the session.
- Actions get unstuck more often. When a step fails, Velora explains what to
  try instead, so the next attempt is a different idea rather than the same
  one again.
- Known limitation: an app opened with no document — TextEdit showing only
  its Open panel, for instance — has nowhere to type, and an action that
  needs to create the document first will still stop rather than guess.
