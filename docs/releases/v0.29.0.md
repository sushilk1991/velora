# Velora 0.29.0

Interrupted model downloads can now be retried from setup or Settings without
starting setup over.

## Model downloads

- Setup and Settings show download progress, verification, loading, and errors
  separately for speech and writing models.
- Temporary connection failures retry automatically. Retry Now tries again;
  Restart Download discards incomplete files while keeping verified completed
  files. An incomplete file starts over when it cannot safely continue.
- Dictation and the first guided try work once speech is ready, even if the
  writing model still needs attention.
- Changing models keeps the working model and saved choice until its
  replacement loads successfully.
- Installed models load offline, including after the writing engine restarts.
- Settings shows model storage. Direct cache removal is unavailable while the
  engine manages downloads; Restart Download keeps completed models.

## Reliability

- Cold writing-model loads have more time to finish. Voice Edit distinguishes
  loading from inference instead of treating both as the same stalled request.
- Retry and Restart wait for the previous download worker to stop before
  starting another.
- Reconnecting or cancelling cannot turn an accepted model change into a
  rejection or replay an already-sent reply.
- Importing a different speech-model choice while disconnected leaves settings
  unchanged and asks you to reconnect first.
- Speech recognition and writing cleanup still run on this Mac.

## Upgrade

Replace the existing app in Applications with the new DMG, or update in-app.
Preferences, history, modes, and dictionary entries are preserved.
