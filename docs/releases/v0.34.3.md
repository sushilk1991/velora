# Velora 0.34.3

- Fixes dropdown menus in Settings (such as Microphone) failing to open over full-screen apps, refreshes Screen Recording status automatically, and shows a System Settings shortcut when Calendar access is off.
- Eliminates mismatched corners on the Settings tab switcher and stops layout shifts from scrollbars when switching tabs.
- Replaces nested model accordions with a direct speech and writing model catalog showing recommended picks, downloaded status, inline progress, and one-click removal.
- Highlights live streaks in Stats across the Active days tile and 12-week heatmap, and replaces Ready in with an adaptive End-to-end time chart showing average speech vs cleanup time.
- Redesigns History with crisp 28 pt app icons, click-anywhere inline expansion for full transcripts, and focused Change Mode, Re-transcribe, Play, and Edit actions.
