# Velora 0.24.1

Reading the words on your screen is now simply part of dictation, so
the switch that turned it off is gone.

- Settings › Dictation no longer has “Read on-screen text for
  spelling”. If you had turned that switch off, on-screen reading is
  active again: every dictation except external listening and Action
  recording now gathers spelling hints from the text near your cursor,
  and from the active window when that text is thin.
- What the reads leave behind is unchanged: nothing is saved.
  Screenshots are discarded after recognition, and the recognised text
  and the spelling hints never reach history, your dictionary, or the
  network. Password and other secure-input fields are still skipped.
- Screen Recording stays optional and is still yours to grant or
  revoke. It only enables local Apple Vision OCR for sparse windows;
  the ordinary reads run through Accessibility without it.

## Upgrade

Replace the existing app in Applications with the new DMG, or update
in-app. Preferences, history, modes, and dictionary entries are
preserved.
