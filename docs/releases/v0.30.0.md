# Velora 0.30.0

Action Mode can flip settings switches, run menu commands, and find controls
in busy windows.

- Commands such as "turn on Wi-Fi" open the right page in System Settings and
  flip the switch. If the switch is already on, Velora says so and leaves it
  alone.
- Action Mode turns switches on or off, picks sidebar rows, and expands or
  collapses sections, and checks that the app shows the new state.
- Action Mode can run commands from an app's menu bar.
- In busy windows, Action Mode searches for the control it needs instead of
  stopping.
- Action Mode reads long lists and deep windows in full.
- Speech recognition and writing cleanup still run on this Mac. Preferences,
  history, modes, and dictionary entries are preserved.
