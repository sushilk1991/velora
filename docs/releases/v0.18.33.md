# Velora 0.18.33

Action Mode now works in the target app without taking over your screen.

- Keep using Telegram or another app while an action runs in the background.
- Velora checks the target again after each click before choosing the next step.
- A task completes only after Velora sees and rechecks the requested result.
- Actions stop safely if the app process, window, or user input changes the target.
- The completion card opens the target app only when you click it.
