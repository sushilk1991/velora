# Velora 0.32.0

- Correct past dictations, remember spellings with Undo, and reformat saved text without needing the recording.
- Create and try writing recipes, expand saved snippets, and apply editing or translation presets.
- Import recordings into Meetings, play back linked passages, and export SRT or WebVTT subtitles. Fine subtitle timing is available with full Whisper Turbo.
- Review meeting chapters, action checklists, and editable recaps, with an optional experimental live preview.
- Use Velora from Mac Shortcuts and choose English or Spanish for the interface.
