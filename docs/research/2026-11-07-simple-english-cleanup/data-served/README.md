# Public rehearsal with actual app request fields

The final serving calibration has **290 TRAIN / 1,427 unchanged DEV** rows in `approved.jsonl`. It starts from the [240-row targeted rehearsal](../data-targeted/README.md), adds eight original Muse layout examples independently approved by Terra, and represents eligible existing public Note lists as stock Default and Smart Terminal requests. Targets remain byte-identical to their approved parents. No owner recording, transcript or reference is a training example.

`candidates.jsonl` preserves the initial 300 TRAIN / 1,427 DEV rows. An independent full-text review checked all 300 training pairs against all nine complete instruction templates, excluding nine incompatible and one uncertain target before training. The review found deleted qualifiers, wording rewrites, Message casing conflicts and one task-numbering conflict. No replacement targets were generated. This extra check demonstrates that earlier approval does not establish compatibility after changing instructions.

The real `benchmark_personal_student.controls()` builds instructions with the production formatter. Requests include mode, app category, FULL strength, language auto/en, 37 additional public vocabulary entries, and irrelevant synthetic caution words. All nuisance vocabulary is sourced from original TRAIN. Train uses three exact-string partitions; the serving development probe uses a fourth. Two casefold overlaps remain (Meridian/meridian and HomePage/homepage); this is not an unseen-vocabulary test. These fields are synthetic public context, not a copy of the owner's configuration. Two parent rows were excluded before context review: one required previous-text context; the actual terminal gate bypasses cleanup for the other. The manifest records them.

The separate `dev-probe.jsonl` mechanically adapts the existing 192 public development cases to these app fields; all targets and original support/repair/literal annotations remain unchanged. It contains 185 supported references. This is a serving stress test and an exposed development suite, not an untouched accuracy estimate. Some original references may become less suitable under changed instructions; independent output review remains necessary. The original 1,427-row validation set is unchanged and its loss is diagnostic, not the checkpoint selector.

An initial calibration attempt used an all-split nuisance pool, including DEV-only terms. It was interrupted after213.25 seconds with no saved checkpoint and excluded from qualification. The corrected pool uses TRAIN only; the raw/target/instruction-template review packet is byte-identical, with the same ten exclusions. Training restarts from the original H512, never the interrupted attempt.

The corpus passes exact-content, eight-word-overlap and connected-component isolation against the frozen exclusions. TRAIN also passes the original dev192 and fresh256 guards. Passing these checks does not establish independence from a base model's unknown pretraining. Source licenses and synthetic provenance are retained in `sources.json`; actual model training and results are documented in the [parent report](../README.md).

`candidate-token-preflight.json` refers to the 300-row candidate file: maximum full sequences 923 TRAIN / 620 DEV, no overlength exclusions at 2,048 tokens. The actual trainer separately validates the approved 290-row file. The tokenizer explicitly returns token lists, matching MLX's wrapper. The initial standalone diagnostic incorrectly counted a Transformers dictionary and was invalidated locally; it was not used by training or selection.

Hash paths in copied review records refer to their original local filenames: `reviewed.jsonl` means the exported `candidates.jsonl`, and `context-compatibility-review.json` means `context-review.json`. SHA256 binds the bytes despite those descriptive export names. Check `SHA256SUMS` from this directory.

A separate post-hoc stronger prompt-isolation audit also passes. It guards instruction/context and vocabulary content while exempting 146 explicitly inspected generic templates. `sources-prompt-isolation.json` and `prompt-isolation-audit.json` record that check; the actual training ledger remains unchanged.

It amended eight targets, including mode-required casing/punctuation and verbatim Code handling, leaving183 supported/eight uncertain/one invalid. The original192 are retained. `contract-audited-dev.jsonl` changes evaluation annotations only, never model input fields or TRAIN. The corrected preservation gate still fails; this audit does not promote J. The JSONL, hash summary and pre-recompute registration are included.
