# Targeted public correction rehearsal

This corpus has 240 TRAIN rows: 96 existing public repair examples, 96 existing public examples requiring no changes, and 48 new synthetic examples generated by Muse and independently reviewed by Terra. The 1,427 original DEV rows are unchanged.

The parent corpus and source ledger are in [the English-scale data export](../../2026-11-07-lfm3-english-scale/data-large/README.md). Existing train examples are selected by fixed hash order with one example per scenario family. The manifest records all selected public IDs and input hashes. The added source uses the existing project-generated policy. This is targeted rehearsal, not a new broad training corpus.

Scenario-specific hints were removed from the new instructions before final review; examples use generic Default/Message instructions or an explicit verbatim Code contract. Initial review corrected two targets; final review under generic instructions made six further adjustments, including five Message punctuation changes. Targets contain no extra facts. These are model-reviewed labels, not human-certified truth.

All training rows passed the existing exact-content/eight-word and connected-component isolation checks against the frozen exclusions, development probe and public challenge. No owner text supplied training examples. Private owner references were used only by the exclusion check and later outcome evaluation.

Training uses the existing canonical student JSON contract with thinking disabled. Model weights and validation outcomes are reported in the parent research note; a valid corpus alone does not qualify a model.

A separate post-hoc stronger prompt-isolation audit also passes. It guards instruction/context and vocabulary content while exempting 137 explicitly inspected generic templates. `sources-prompt-isolation.json` and `prompt-isolation-audit.json` record that check; the actual training ledger remains unchanged.
